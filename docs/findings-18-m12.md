## 2. 三个科学结论

1. **base bake 是规模路线的瓶颈**：教师相同（FP-8B 0.830）、剂量相同（1.2ep）时，8B 学生（0.505）反而低于 1.7B 链学生（0.530）——差异全在基座：v0.7 站在五轮链条的 1.24× 基座上，8B 只有单轮 2.378× 的新鲜烘烤。**知识转移效率是基座分布质量的函数**（链条方法论的反向验证）
2. **弱底子上剂量曲线提前反转**：M11（好基座）峰在 2.4ep；M12（弱基座）1.2ep 即峰、2.4ep 侵蚀（sciq −0.061 而 ARC +0.013，流间此消彼长）——**剂量最优点的位置本身是基座质量的函数**
3. **同预算下链条抛光 > 参数放大**：8B 每步成本 ×4.7，把本可用于多轮链条抛光的算力吃掉；规模溢价需要官方量级（200-800 A100·时）的 base bake 才开始回报——与 findings-15 的官方反推（工业算力填容量）互为印证

## 5. 附录：结论三（链条抛光 > 参数放大）的完整论证

**两条花钱路线的算术**（同 ~20-25 A100·h 预算）：

| | 路线 A：链条抛光（1.7B×5 轮） | 路线 B：参数放大（8B，M12 实际执行） |
|---|---|---|
| 成本结构 | 每轮 ~1.5-2h，从上代发布物自举，质量累积 | 每步 ×4.7，同样 5000 步花 4.7 倍算力 |
| 预算去向 | v0.2→v0.7 四轮抛光的全部算力 | 被 Stage 1 一次性底子烘烤吃光 |
| 终点 | sciq 0.530 / ppl 1.014×FP-1.7B | sciq 0.505 / ppl 2.378×FP-8B——**双轴皆输** |

**三个机制叠加**：

1. **单位参数训练强度随规模下降**：同 20.5M token 摊在 4.7 倍参数上，每参数打磨次数 ÷4.7——1.7B 烘到 1.41×，8B 同步数只到 2.378×（"夹生"）。Stage 1 的 28.69 与 M4 的 28.77 绝对值巧合即此：参数多、没喂饱，规模不兑现
2. **知识注入需要熟底子**：好基座（1.24×）剂量峰 2.4ep、sciq 0.530；弱基座（2.378×）峰提前到 1.2ep、只有 0.505 且过剂量侵蚀——纸面容量 4 倍，可用容量被夹生度锁死
3. **链条的复利 vs 放大的一次性**：链条每轮从上代最优起步、单调爬升、每轮小钱；放大路线全部预算押注一次性烘熟，预算内必然烘不熟

**与 findings-15 的闭环**：官方付了 200-800 A100·时的 base bake 入场费 → 容量填到 98%；我们不付 → 容量填不上。同一 trade-off 的反推侧与实测侧。

**一句话**：规模是富人的杠杆，链条是穷人的复利——v0.7 是这句话在 1.75bpw 世界的实证。
