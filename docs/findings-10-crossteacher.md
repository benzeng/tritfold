**两个维度几乎追平 FP**（ppl 101%、ARC acc 99%）。1.75 bpw 压缩在语言建模和似然排序上**不再以质量为代价**——只要教师够好。

训练曲线：22.98 → 20.62 仅用 700 步（v0.3 需要 1400 步到 25.20），之后在 20.6-21.5 研磨。skip 0 全程、护栏无压力。

## 2. ARC acc/acc_norm 分歧的机理

acc ↑（0.208→0.355）而 acc_norm ↓（0.264→0.245）——分布锐化的签名：

- 8B 教师分布更锐（更自信），学生继承了锐度
- 原始总 logprob 排序：锐分布 → 正确选项总分更高 → acc 大幅提升
- 长度归一化：锐分布 → 短选项 per-token 分数偏高 → 归一化反而过度惩罚长选项 → acc_norm 回落

**acc 是更本质的指标**（不引入长度偏差）；acc 0.355 ≈ FP 0.358 是真正的似然排序能力。

## 3. 知识维度的部分突破与剩余天花板

sciq 0.398→0.439（+10.3%），达 FP 的 63%（从 57%）。**改善真实但幅度远小于 ppl 改善**。

抽检确认：红行星仍无 Mars（"a celestial body that orbits the Sun... about 1000 kilometers"）；雷声闪电知道解释的框架但内容仍是编的。生成行为的知识水平没有质变。

### 修订版知识饱和定律（替代 findings-8/9 的版本）

> **三值模型的上限 = min(教师质量, 容量约束)**
> - 语言建模与似然排序：容量足够 → **教师是瓶颈**（8B 后几乎无损）
> - 深层知识检索（sciq 型生成）：容量部分受限 → 教师和容量**共同**瓶颈

这比"纯容量论"乐观得多。剩余的 sciq 差距（63% of FP）是真正的容量税；32B/72B 教师可能再推几 pp 但边际递减；FP 级知识需要规模（M9）。

### 理论根源

| | 分布匹配（怎么说话） | 知识内化（知道什么） |
|---|---|---|
| 数学本质 | 输出分布形状（低秩） | 特定映射存储（密集查找表） |
