## 1. 重建目标与硬约束（来自代码取证，必须先满足）

任何"等效方案"的出货物必须满足以下已验证的 artifact 契约：

| # | 约束 | 出处 |
|---|---|---|
| C1 | 权重在**固定**块 1024 Hadamard 基下，R = H_n·S/√n，S 为固定 ±1 向量（随模型发布） | hadamard_packing.json / prism.hadamard.* |
| C2 | 每组 128 权重 = {-s, 0, +s}，**只有一个 FP16 scale，无 shift/bias**（MLX 包里的 bias 被白皮书明确称为冗余） | ggml-common.h block_ptq1_0 / 白皮书 §2.3 |
| C3 | 成品权重对 RTN **无损**（打包器就是朴素 amax+round） | ggml-quants.c quantize_ptq1_0 注释 |
| C4 | 折叠只沿输入特征轴（axis=-1，fold-before-matmul）；embedding 存旋转域、查表后逆变换（与 lm_head 共享张量） | conversion/base.py |
| C5 | 敏感小岛保持全精度：归一化、线性注意力循环状态路径（in_proj_a/b、conv1d、A_log/dt_bias） | 白皮书 Table 2 |

C2 是一个强鉴别器：**排除了带 shift 的三值方案**（如 TernaryLLM 的 DLT α·T+γ）——PrismML 的训练必须把权重驱动到**对称**三值字母表上。

## 2. 三块公开拼图

### 拼图 A：创始人理论 = 方法内核（Akhtiamov, Ghane, Pooladzandi, Hassibi）

**A1. 强正则产生离散（2311.02270 / 2402.10474，ISIT 级别理论）**
过参数化正则最小二乘 min ‖XW−Y‖² + λf(W) 中：
- f = ℓ∞：最优解取**夹逼形式** w_i = clamp(Ξ·G_i, ±δ/λ)——λ→∞ 时所有坐标贴到边界 ±δ/λ，sign(W) 无损（Q-函数误差公式精确给出）；
- f = ℓ1：prox 是软阈值 → 精确稀疏（18/2000 稀疏度下误差 3e-4）；
- **ℓ1 + ℓ∞ 组合 = 先软阈值再夹逼 → {0, ±δ/λ}，即三值**；
- 2402.10474 Thm 4.1：λ→∞ 的 ridge 在所有凸正则里误差最优，而 ℓ∞/ℓ1 解"几乎一样好"——即**强插值约束 + 离散化偏置 ≈ 免费的离散化**。

**A2. 算法引擎 = 矩阵镜像下降（2602.18997，核心定理）**
矩阵 SMD：∇ψ(W_t) = ∇ψ(W_{t-1}) − η∇L_t(W_{t-1})，在过参数化约束 A(W)=b 下**指数收敛**到

  W* = argmin D_ψ(W, W₀)  s.t.  A(W) = b   （KKT: ∇ψ(W) − ∇ψ(W₀) = Aᵀλ）

**ψ 决定收敛解的结构**（‖·‖²_F→最小范数；Schatten p→1⁺→低秩）。这把"量化"重新表述为：**选一个在三值点 {-s,0,+s} 处曲率最小的逐元素 ψ，SMD 就收敛到"满足行为约束的、最接近原权重的类三值解"**。隐偏置与步长无关（可复现），且 ψ 加 ν‖·‖²_F 即可恢复强凸（论文自己的 Schatten 构造）。

**A3. 加速器（2603.10485）**
对偶空间预条件 ∇K：各向同性 K = h(‖·‖_F)（归一化/裁剪）与保张成 ∇K(Z)=Z·K̃(Z)（平滑矩阵弹性网/Muon 式）被证明**不改变隐偏置、只加速**（线性收敛到同一极限）。反例（Prop 2）：逐元素 Adam 式预条件使极限依赖步长——收尾阶段禁用。
Remark 2 警告：初始化若已接近插值解则隐偏置失效——所以扰动/旋转后的初始化是必要的。

**A4. 无损化的理论许可证（2510.16250）**
Random Features 模型：除最后一层外全部权重换成方差匹配的 ±1，端到端测试误差**渐近不变**（高斯等价 + CGMT + 普遍性）。条件：权重大致 iid、方差 1/d。

### 拼图 B：旋转基底文献 = 让 A 的假设成立

- **QuaRot（2404.00456）**：固定 Hadamard 的四处插入点全部给出精确机制——R1 残差流（吸收 RMSNorm 的 diag(α) 后并入 embedding 与所有块输入/输出矩阵，数学恒等）、R2 V/O 逐头（利用 W_v·P·W_out 复合结构）、R3 post-RoPE Q/K 在线（分数不变性）、R4 down-proj 前在线。数据免费，70B 五分钟。
- **SpinQuant（2405.16406）**：同一骨架但 R1/R2 用 Cayley SGD 学习（Stiefel 流形），比最好随机基好 1–16 个零样本点——证明**基的选择在 ≤2bit 时是生死问题**；同时证明随机 Hadamard 基本身已相当强（方差可用符号向量 s 搜索压缩）。
- **QuIP#（2402.04396）**：incoherence processing 的原始表述——RHT 使权重坐标近高斯。

### 拼图 C：低比特训练工程 = 目标函数与优化细节

- **PV-Tuning（2405.14852）**：交替最小化——P 步（连续码本/scale 用 Adam 反传）+ 子空间 V 步（每步只对 |Adam 更新| 最大的 τ≈1% 权重做"吸附到最近码字"，信赖比 ‖Δx‖/‖x‖≤0.01）。系统性强于 STE，码学习率 3e-3 仍稳定。**2.07 bpw @ Llama-2-70B 达 FP 的 ~97.7%**（公开文献最接近 Bonsai 指标的点）。目标 = 对 FP teacher logits 的 KL。
- **BitDistiller（2402.10631）**：CAKLD（γ 混合正/反 KL）+ 仅 2K 条教师生成样本，7B 只要 3 A100 小时——证明**数据可以很省**。
- **TernaryLLM（2406.07177）**：三值 STE QAT 的上限参照（Llama-2-7B 1.58bpw ≈ FP 的 89%）——说明**纯 STE 三值到不了 98%**，必须有更强的优化引擎。
- **OneBit / LLM-QAT**：SVID 初始化（sign + 秩一幅度分解）、自生成数据配方（前 3–5 token 贪心后采样）。

## 3. 关键洞见：旋转是理论与现实之间的桥

把三条线拼起来，第二代 Bonsai 引入固定 Hadamard 基的原因就清楚了：

1. A1–A4 的严格理论全部假设**权重近似 iid 高斯/非相干**（GMM、Random Features、方差匹配）；
2. 真实 LLM 权重有 outlier、通道相关——理论条件不成立，直接强正则/SMD 三值化只能到第一代水平（95%/90% 保真）；
3. **固定 RHT 把权重坐标"制造"成近高斯**（QuIP#/QuaRot 的 incoherence），恰好恢复理论成立的 regime；
4. 在非相干基下，amax 尺度变紧、对称三值（C2）自然成立（旋转后各组近似零均值——所以不需要 shift！）、RTN 变无损（C3）；
5. 于是训练侧只需在**旋转基里**执行 A 的优化：这与 SpinQuant **互为镜像**——SpinQuant 学旋转去适配权重，Bonsai 固定旋转、训权重去适配基。固定基换来可复现性（2602.18997 的步长无关隐偏置）与免学习的部署侧。

这也解释了 C5：线性注意力循环状态路径是全模型离"iid 非相干"最远、数值最敏感的部分（递归状态会放大误差），所以被划出约束集。

## 4. 等效方案（可实现的重建管线）

输入：FP16 模型 W₀、校准语料 D（RedPajama 式去偏采样，~1M token 批）、教师 = 冻结的 W₀。

**Phase 0 — 基底插入（数据免费，小时级）**
- 折叠 RMSNorm 的 diag(α)；按 QuaRot R1/R2/R4 机制把块对角 R = H_1024·S/√1024 并入可合并位置；在线位置保留给运行时（对应 fork 的 FWHT 路径）。
- 混合注意力改动：softmax 层照 QuaRot；线性注意力/GDN 层无 QK 分数结构，跳过 R3，对 ssm_out 按 fold-before-matmul 处理（fork 白名单已验证此路径）；GDN 的 V 序保持训练序、激活侧置换（fork 契约已实现）。
- 全精度小岛（C5）从可训练集剔除。
- 符号向量 S：固定随机种子生成一次；可离散搜索少数候选取校准 MSE 最优（压缩 SpinQuant 报告的随机基方差）。
- 产出：旋转后模型 W′₀ = W₀R⁻¹（折叠处）+ 与运行时一致的 FWHT 插入。

**Phase 1 — 初始化（分钟级）**
- Z₀ ← W′₀；每组尺度 s_g 初始化 = amax(Z₀ 的组)；T₀ = round(Z₀/s_g)（TWN 变体亦可）。
- 按 2603.10485 Remark 2，从 Z₀（损失非零处）出发，而非已收敛插值点。

**Phase 2 — 离散约束蒸馏（核心，数百 GPU·时）**
目标：min L_kd(student(Z), teacher) + ε·L_feat，student 的有效权重 Ŵ = s_g·T（按 C2 对称三值），约束在旋转基中。
两种引擎（理论派 / 工程派，殊途同归）：

- **E1（理论派，2602.18997 直译）**：对 Z 跑矩阵 SMD，逐元素势 ψ(z) = Σφ(z_ij)，φ 为"三架"势——在 {−1,0,+1} 处取极小（如分段二次 φ(z) = min(z², (|z|−1)²) 的 ν-强凸平滑化 + νz²/2）；按 Thm 1 指数收敛到 argmin D_ψ(Z,Z₀) s.t. 蒸馏约束。加速器用 2603.10485 的各向同性/保张成预条件；收尾阶段禁用逐元素 Adam 式预条件（Prop 2）。
- **E2（工程派，PV-Tuning 直译）**：码字 = 每组 {−s_g,0,+s_g}（单参数码本）。P 步：Adam 更新所有 s_g、小岛张量、embedding（lr 3e-4）；V 步：取 |Adam 更新| top-τ（τ≈1%）权重吸附到最近三值点（信赖比 0.01）；码 lr 3e-3，恒定 lr，β=(0.9,0.95)。
- 目标函数（两派共用）：KL(student‖teacher logits)（PV/BitDistiller/OneBit 一致）+ 前 ~18 层余弦特征 KD（TernaryLLM OFF，δ=5，ε=0.001，抗 outlier）。
- 数据：BitDistiller 证明 2K 条教师样本可用；PV-Tuning 用 1M token 批更好；领域补齐（数学/代码）按 BitDistiller 的 domain top-up。
- 成本估计：7B 单卡可行；27B ≈ 200–800 A100 时（PV-Tuning 70B 数据点外推）。

**Phase 3 — 吸附与清单（分钟级）**
- 训练末权重已集中于三值点；最终 T ← round(Z/s_g)，s_g ← 组 amax（RTN 无损即达成，C3）。
- 验证无损：‖s_g·T − Z‖∞/amax < 1e-3 全张量通过。
- 输出 hadamard_packing.json（block_size=1024、符号表、折叠张量、角色；embedding 标 inverse-after-lookup）。

**Phase 4 — 打包（现成工具）**
- fork 的 conversion/ 写 GGUF（含 prism.hadamard.* 契约）→ llama-quantize 转 PTQ1_0/PQ2_0 → 运行时直接加载。

## 5. 验证计划（有地面真值可对拍）

PrismML 已发布上一代 Ternary-Bonsai-1.7B/4B/8B（Qwen3 基座，**无旋转**的一代）——完美的分级验证：

1. **L0 机制验证**：Qwen3-0.6B 级别，Phase 0+RTN 三值，测 Wiki2 ppl；预期：旋转后比不旋转显著好（QuaRot 效应），但都远差于 FP（缺 Phase 2）。
2. **L1 小规模全管线**：Qwen3-1.7B 跑全流程，对照已发布 Ternary-Bonsai-1.7B 的基准分（MMLU 等，白皮书附录 C 有数）。达成 ±1 分 = 管线等效。
3. **L2 消融**：E1 vs E2 引擎、有无特征 KD、s_g 初始化（amax vs MSE 最优）、S 的候选数。
4. **L3 27B 外推**：混合注意力 + 262K 上下文；验收 = 对 FP 保真 ≥98%（20 基准套件）+ AIME/LiveCodeBench 不塌（白皮书指出这两类最先退化）。

## 6. 未决问题（公开信息无法确定的部分）

1. **E1 还是 E2（或混合）**：创始人理论指向 SMD/镜像下降，但 PV-Tuning 交替法在工程上等效且已验证；出货物无法区分。
2. **逐层还是端到端**：A1 的逐层凸规划视角 vs Phase 2 的端到端蒸馏；可能先逐层初始化再端到端。
3. **s_g 的处理**：联合训练还是闭式交替；amax 是最终打包尺度，训练期可能用 MSE 最优尺度。
4. **数据构成与算力**：无任何公开数字；Bonsai 2 的"推理努力 xhigh/medium"行为保留暗示用了带思维链的教师数据。
5. **98.2% 的最后一里路**：公开最佳 ~97.7%@2.07bpw（70B，旧基准）。差距可能来自：更新的基座（Qwen3.8 更强）、混合注意力主干、未公开的 ψ/数据细节。
6. **二值（1-bit）支线**：同一框架 ℓ∞ 单独使用 → {±s}；Bonsai 1-bit 90% 保真与理论"sign 无损（线性/RF 模型）"之间的差距 = 深度非线性网络的残余难度。
