## 3. 分析：为什么旋转救不了 RTN 三值

1. **84% 置零是崩溃主因**：Gaussian 权重 + amax 尺度（组 128，E[amax]≈3σ）→ RTN 阈值 1.5σ → ~84% 权重归零（实测 83.4–87.4%，与理论一致）。1.58 bpw 的纯 RTN 在任何基下都是灾难。对照：官方 artifact 实测零占比 32.8%（近最大熵三值）——**差距全部由训练阶段贡献**，这与重建文档 §8.4 的推断互为印证。
2. **权重侧旋转无效是数学必然**：Qwen3-0.6B 的预训练权重本就近高斯（无非相干性问题），正交变换保持高斯 → 旋转前后逐层误差几乎相同（比值 ≈1.0）。QuaRot 的旋转收益主要来自**激活**量化（本测试激活全精度）与权重 outlier 场景；对"权重-only 三值 RTN"无显著作用。个别层（blk27_mlp_down，激活峰度 1093）旋转反而略差——旋转把激活 outlier 摊平后误差分布改变。
3. **旋转的真正作用在训练侧**（与重建文档 §3 一致）：固定 RHT 制造出理论（A1–A4）成立所需的近高斯非相干 regime，并保证成品在旋转基下对称三值 + amax 无损（artifact 已实证）。它是"让训练能收敛到无损三值"的舞台装置，不是"让 RTN 变好"的量化技巧。

## 4. M2 验收判定（修订后）

原验收门"旋转 RTN ≫ 无旋转 RTN（QuaRot 效应）"**对权重-only 三值不成立，已否定**。修订为：

| 项 | 结果 | 判定 |
|---|---|---|
| 旋转机制数学恒等（折叠/逆变换/在线 FWHT） | rel 误差 0.24%，argmax 99.61% | ✅ |
| RTN 统计与理论一致（零占比 ~84%、amax 行为） | 实测吻合 | ✅ |
| 与 artifact 约定一致（g128 沿输入轴、amax、对称三值） | 实现即契约 | ✅ |
| ~~QuaRot 效应（旋转显著改善 RTN ppl）~~ | 9× 改善但双方均崩溃；逐层比值 ≈1 | ❌ 证伪，不再作为门 |

**M2 通过（按修订后的门）**；级联修订：M3 验收门 ② 从"显著优于裸 RTN"（基线 1e8，无区分度）改为"**训练后三值 ppl 逼近 FP（0.6B 目标 ≤1.5×FP=29）**"；M3 训练健康指标增加"零占比向 ~1/3 收敛"（M1 实测指纹）。
