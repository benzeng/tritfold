# 路线图：三值模型达到原 Qwen3-1.7B 能力的路径分析

- 日期：2026-10-05（v0.7 发布后）
- 输入：v0.7 终盘（sciq 0.530=76% FP、ARC 0.319=84% FP、ppl 20.70=1.014×FP）+ 三杠杆可加性 + 对症双向验证
- 性质：战略决策文档（M11/规模线的立项依据）

---

## 1. 差距解剖：四个维度，四种性质

| 能力维度 | v0.7 现状 | Qwen3-1.7B FP | 差距性质 |
|---|---|---|---|
| 语言建模（wiki ppl） | 20.70（1.014×） | 20.42 | **实质已达标**（协议噪声内；v0.5 曾到 1.01×） |
| 定向判别（sciq / ARC） | 0.530 / 0.319 | 0.699 / 0.378 | **配方未打满**——四杠杆有余量 |
| 广谱闭卷知识（MMLU 等） | 未系统测 | — | 容量 × 语料覆盖，未知域 |
| 自由生成中的事实回忆 | 随机事件（裸续写 ~1/3 命中） | 可靠 | **信息论墙**：1.75bpw 容量本质约束 |

## 2. 路径一：1.7B 三值配方打满（判别类 → 86~90% FP 现实可期）

四个未打满的杠杆（按性价比排序）：

| 杠杆 | 内容 | 预期增益 | 成本 |
|---|---|---|---|
| 教师再升级 | Qwen3-14B（28GB bf16，**缓存阶段设计已解锁**——教师规模与训练 VRAM 解耦，边际成本只剩缓存时间） | sciq +0.02~0.04 | 缓存 ~20min |
| 剂量曲线 | sciq 流 1.2 → 2.4/4.8 epoch（dose-response 是"对症"定量化的关键曲线） | +0.02~0.05（若未饱和） | 同会话 |
| 训练步数 | 1500 → 4500 步（M4 先例 5000 步；缓存目标下训练便宜） | +0.02 | +3h |
| 全深度 hook | 18 → 28 层余弦锚 | 未测 | 免费 |

乐观合成：sciq 0.530 → **0.60~0.63（86~90% FP）**、ARC → 0.34~0.36。**100% 不可期**——每权重 1.75bit 装不下 FP 每权重 16bit 的信息。

**先决测量**：8B 教师自身的 sciq（至今未测）。若教师 0.78 而学生 0.530，瓶颈在转移效率（→加步数/满深）而非语料（→加剂量无效）。

**决策门（已判定 2026-10-05，findings-13）**：峰值 0.559 < 0.58 → 容量墙确认，M12 立项。剂量内点最优 ~2.4ep、转移效率上限 67% of 8B 教师。原设想门：M11 后 sciq ≥0.58 → 1.7B 线以"~90% FP 判别 + 1.01× ppl"收官；否则剩余差距确认为容量墙，转路径二。

## 3. 路径二：换赛道——三值 8B（"能力达标"的主攻线）

若目标是"达到原 1.7B 的能力"而非"1.7B 模型的三值化"：

**三值 8B ≈ 1.75GB < FP16 1.7B（3.4GB）——字节一半，参数 4 倍。**

- 1.75bpw 低到足以用更少字节买 4 倍参数，scaling law 站这边
- M4 已证三值 QAT 从零 5000 步在 1.7B 可行（1.41×FP）；8B 同管线（步成本 ×4.7，5000 步 ≈ 15h）预期 **~1.2×FP**——ppl/知识全面超 FP 1.7B
- 管线复用：基础 QAT（~80 单位）→ instruct/knowledge/stacked 链（共 ~150-200 单位，$80-120）
- 对比 M9 27B（$200）：更便宜、更直接命中"能力达标"目标

## 4. 路径三：自由回忆的墙（诚实部分）

判别（似然口径）与自由回忆（生成口径）的分离不因配方改善而消失——M9′ 运行时对照已证 Mars 类回忆是两臂共有的低概率事件。生成口径追平 FP 的唯一路径是参数规模（路径二）；工程答案是 **RAG**，恰好补的是幸存的检索模式（与"上下文联想存活"发现自洽）。

## 5. 执行序列

1. **M11**（15 单位，单会话）：剂量 ×3 曲线 + 4500 步 + 28 层 hook + 顺带测 8B 教师 sciq
2. **决策点**：按 §2 决策门分流——1.7B 收官 or 确认容量墙
3. **补基线**：MMLU / 指令跟随 / 长上下文系统测（"原 1.7B 能力"的全貌对照，现仅两探针+抽检）
4. **三值 8B 立项**（路径二，M12）：决策门已确认（M11 容量墙）。**M11.5 校准更新**（findings-14）：官方 27B 三值知识维反超 FP（120%/108%）、分布维 1.335×——知识侧 ~100% 保留已被工业背书，我方 67% 是配方差距非表示论障碍；**M12 成功判据：ppl ≤1.2× FP-8B 且 sciq ≥0.70**；纯 67% 转移外推不够（0.56），需 32B 教师（0.88+ × 80% → 0.70 踩线）
5. M9 27B：仅在路径二仍不达标时考虑（当前不推荐）
