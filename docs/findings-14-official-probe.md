# M11.5 战报：官方 Bonsai 2 27B artifact 能力探针——三值不弱反强，且揭示"分布-知识"镜像 trade-off

- 日期：2026-10-05
- 载体：`notebooks/tritfold-m115-official-probe.ipynb`（A100 ~2.5h；配对 C++ 打分器 probe_scorer.cpp + 同一份 TSV 双模型）
- 对象：官方 `Ternary-Bonsai-2-27B-PQ2_0.gguf`（7.2GB，注意：白皮书旗舰是 1.76bpw/5.93GB PTQ1_0 打包，探的是其速度优化 PQ2_0 变体，同一权重）vs `unsloth/Qwen3.8-27B-Q8_0.gguf`（FP 参照，量化损失 <1%）

## 1. 主结果：同协议配对四维

| 维度 | 官方三值 27B | Q8 参照 | 比值 |
|---|---|---|---|
| sciq acc / acc_norm（n=845 去污染） | 0.800 / **0.743** | 0.733 / 0.619 | **120%** |
| ARC-c acc / acc_norm（n=1172） | 0.504 / **0.533** | 0.491 / 0.493 | **108%** |
| wiki ppl（wt2_30k, c512, 同工具） | 8.41 | 6.30 | **1.335×（更差）** |
| 三题抽检（含 think 风格） | 全对（Mars/mitochondria/光速） | 全对 | 持平；同款推理风格（血统同源实锤） |

**回答立项问题："官方三值比原版弱吧？"——不弱。知识判别反超（120%/108%），生成抽检全对；代价在分布维：ppl 1.335×。**

## 2. 两个独立证据链互证

1. **白皮书自证**（我们用 pypdf 提取）：20 基准总分 83.9 = FP16 基线 85.4 的 **98.2%**，超 Qwen3.6-27B（83.6）；MMLU-Redux 97.4%、GPQA 94.7%、AA-LCR 98.7%、GSM8K 99.5%——知识类保留率与我们的探针结论同向
2. **探针反超 vs 基准略低**的差值（120% vs 98%）符合锐化效应：闭卷似然探针奖励尖锐分布（v0.5 锐化签名的宏观版）；生成式基准更接近真实能力

## 3. 核心发现：分布-知识镜像 trade-off（零和在 27B 的宏观证据）

| | 分布维（ppl） | 知识维（探针） |
|---|---|---|
| 我方 v0.7（1.7B，1 天训练） | **1.014×**（近无损） | 67% of 8B 教师 |
| 官方 27B（200-800 A100·时） | 1.335× | **≥100%** |

两条线互为镜像：我们把分布打满、知识打折；官方把知识打满、分布打折。**即使 40-160 倍算力也没能两维同时无损**——容量分配零和从 1.7B（M7 zh/know 臂）到 27B（工业级）全程成立。这是"三值化 = 低通滤波 + 知识蒸发"数学框架的最强宏观实证：滤波掉的分布熵与写入的知识在固定容量下此消彼长。

## 4. 勘误与协议注记

- **"官方 1.02×ppl"撤回**：两版 27B 白皮书均无 ppl 数字，早前档案所记 1.02× 为无源推断（M9 规划时引入）。实测 1.335×（wt2/c512 同协议配对；Q8 量化使参照略差，对 FP16 真比值 ≈1.31-1.36×）
- Q8 参照健全性三重验证：生成抽检全对、推理风格与三值同款、ppl 6.30 合理
- **打分器协议校准通过**：C++ scorer 复测 v07（sciq 前 100 题 ×4 选项，本机 CPU）acc **0.560 与 PyTorch 全量真值 0.560 完全一致**、acc_norm 0.570 vs 0.536（+0.034，子集 CI ±0.098 内）——无系统性偏差（BOS/tokenize 类 bug 会造成 >0.1 的漂移），27B 配对数字全部成立

## 5. M12 校准结论

官方在 27B 规模证明了**知识维可以做到 ~100% 保留**（代价 1.33× ppl）——"三值 8B 全面超 FP 1.7B"的知识侧上限被官方背书。我方配方在分布侧已有 1.014×。M12 设计直接受益：

- 纯我方配方外推（67% 转移）：8B 学生 sciq ≈ 0.56，**不足以超 FP 1.7B（0.699）**——需要教师升级（32B 教师 sciq 预计 0.88+，80% 转移 → 0.70 即达标）
- 官方路线启示：知识保留的工业上限 ~100%，我方 67% 的差距是**训练配方差距**（剂量×教师×算力的函数），不是表示论障碍
- 判据更新：M12 的成功标准定为"ppl ≤1.2× FP-8B 且 sciq ≥ 0.70"（双维同时达标才算全面超 FP-1.7B）
