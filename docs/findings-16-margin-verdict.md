## 2. 三层判读

1. **锐化否决**：margin 幅度未变（1.04×）——反超不是分布变尖的探针伪影
2. **翻正画像宽而平坦**：三个桶全部 ≥56% 翻正 + 收支极不对称（+137/−32，损失侧低置信）——三值的答案排序真实更好
3. **大教师否决（白皮书交叉验证）**：官方三值在真实知识基准低于基座（GPQA 94.7%、MMLU-Redux 97.4% 保留率）——外部知识源与"真基准略降"矛盾

**裁定：自蒸馏 + 对症语料的"再校准/解锁"机制。** 基座（thinking 型）闭卷短答案似然系统性失准（0.619 < 1.7B FP 0.699 的异常即信号）；QA 格式对症训练修复排序校准（探针反超至 0.743），真实知识量略低于基座（真基准 94.7-97.4%）。探针口径与基准口径的分离再次出现（knowing 的两种测量不一致——与"知道≠说出"同族但不同维度：**似然校准 ≠ 真实知识**）。
