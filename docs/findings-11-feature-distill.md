## 0. 1a 对照（2026-10-05 完结）：归因修正

1a 臂 = 同教师、同 KL 形式、同 4+2+2 配比、同 1500 步、同 v0.3 GGUF 起点，唯一差异为去掉余弦项：

| 口径 | 1a（纯 KL） | 1b（KL+cos） | 余弦净贡献 |
|---|---|---|---|
| sciq acc_norm | **0.458**±0.034 | 0.485 | +0.027（噪声内，~1σ） |
| sciq acc | 0.471 | 0.536 | **+0.065（≈2.7σ，显著）** |
| ARC acc / acc_norm | 0.236 / 0.268 | 0.246 / 0.279 | +0.010 / +0.011（噪声内，ARC 上无贡献） |
| wiki ppl（训练内） | **25.44** | 26.52 | 余弦付出 ~1.1 ppl |
| 三题抽检（chat） | **2/3 退化循环**（"largest planet"循环、"The question is"×6、字母枚举） | 流畅但错（1/3 框架对） | 余弦 = 生成稳定器（见修正 4） |

四个修正：

1. **余弦的真实角色**：不是"知识通路"的全部，而是在对症语料之上的中等增量。效果集中于 raw acc（argmax 锐化），acc_norm 口径不显著；ARC 上无可测贡献。1b 相对 v0.3 的 +0.087 中约 +0.060 来自别的（见下），+0.027 来自余弦。
2. **+0.060 来自哪里**：1a 相对 v0.3 的大增益触发复查，发现 M7 know 臂的 sciq 流管线 bug（逐条 ≥512 过滤 → 11679 条仅 81 条存活、池 0.041M tok、每窗复用 37 遍、覆盖率 3.3%）。m9p 修正为 concat+整体开窗（1.27M tok / 2485 窗，覆盖 121%）。**"知识饱和定律"的对症语料半边撤回**（详见 M7 findings 勘误）——对症语料经教师蒸馏是真实知识通路，1a 即修正版 know 臂。
3. **三杠杆分解**（sciq 增量，跨配置推断、仅 1a↔1b 为干净双臂）：教师质量（1.7B→8B，空池）+0.041；对症语料（空池→全量，同教师）+0.060；余弦特征（同上其余）+0.027（acc_norm）/ +0.065（acc）。三个杠杆数量级相当、方向独立。**转移是语料特异的**：sciq 流的 +0.060 不外溢到 ARC（1a ARC vs v0.3：acc +0.028 边缘、acc_norm +0.007 平坦）——"对症"按字面生效。
4. **余弦的第二角色：生成稳定器（新发现，初步）**。1a 与 1b 的 ultra 剂量完全相同（2/8），但纯 KL 臂的 chat 生成两题退化为重复循环，KL+cos 臂保持成句。同期 1a 的 teacher-forced ppl（25.44）反而**优于** 1b（26.52）——两个口径分离：**KL 优化 teacher-forced 分布质量，余弦的隐藏态锚定防止 free-running rollout 漂移**（exposure-bias 型塌缩）。单臂三题为初步证据，待 2a/2b 或重复实验确认。

v0.6 发布物不受影响（数字为实测）；变化的是归因叙事：从"几何匹配是知识通路"修正为"对症语料（经蒸馏）为主、特征匹配为辅（锐化 argmax + 稳定生成）"。

### 1a 三题逐题点评（坍缩形态学）

采样口径：temp 0.5 / top-p 0.85 / top-k 20（无 repeat_penalty，循环可见度略放大；1b 同口径不循环，对照成立）：

- **Q1 红行星｜槽位循环**：定义句框架语法完好，但内容槽全被 "Solar System" 空转；"largest planet" 系事实邻域串线（Mars↔Jupiter 属性污染）；"直径 1.6 billion km" 数量级幻觉（差 4 个量级，高频信息蒸发）。格式活得比内容久。
- **Q2 雷声闪电｜标题回声**：无内容尝试，复述问题后 `### The question is...` ×6——用排版反射复读问题。Q→A 映射存活，回应内容坍缩。
- **Q3 发电站｜格式枚举**：`is **A**` + A-L 全填 A——M5″ 字母偏置签名复发。假说：sciq 流教会"问题→答案格式"联想、未装进"问题→事实"——对症语料的格式副作用在生成口径显形（知道 vs 说出分离的又一证据）。

三题同源：**首句成句、1-2 句后分布塌进重复模态**（exposure-bias 形态：提示锚定区正常、自生成区漂移）。与 ppl 更优不矛盾——teacher-forced 与 free-running 两口径分离的实证。1a 的运行时 GGUF 行为未测（廉价补证路径：Drive 的 m9p_1a_qat.pt 导出跑 raw 续写）。
