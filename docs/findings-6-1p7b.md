## 4. 与官方 Ternary-Bonsai-1.7B 的诚实定位

同基座（Qwen3-1.7B）、同表示（1.71–1.75 bpw 契约格式）下的差距与解释：

- 官方（上一代，无旋转）：白皮书附录 C 的基准分口径（MMLU 等），未公开 ppl；其 27B 二代为 FP 的 98.2%；
- 我们：ppl 口径 1.41×FP ≈ 若换算基准分口径，按 0.6B→1.7B 的趋势外推约在 85–90% 保真带；
- 差距来源（与重建文档判断一致）：算力（我们 5000 步×8×512 ≈ 2×10⁷ token、单卡 5 小时；官方 27B 估 200–800 A100·时）、数据构成与课程、以及未公开的训练目标细节。

**结论：公开数学重建的等效管线在 1.7B 上达到质量门内（≤1.5×FP），与官方的剩余差距与重建文档对"秘密训练阶段"的算力估计自洽。**
