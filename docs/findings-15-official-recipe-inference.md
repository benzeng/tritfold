## 2. 逐条推断

**A → 规模是转移效率的主导变量，不需要大教师假设。** 我方 1.7B 墙在 67%（M11），官方 27B 到 98%——与我方 ppl 规模效应曲线（0.6B 1.77× → 1.7B 1.41×）同族。27B×1.76bpw 的状态量是我方学生的 ~15 倍，容量本身即可解释 A。教师大小问题从 55:45 进一步偏向自蒸馏。

**B → 海量任务对症语料实锤（这是最强的一条）。** 纯压缩不可能在指令跟随上**超过**基座——唯一解释是训练混合里含 IF 定向数据（IFBench/IFEval 型语料，且与其评测套件任务类型对齐）。官方把我们的"对症语料杠杆"用到了工业剂量和广度（我们的 M10/M11 证明该杠杆双向有效、内点最优 ~2ep）。

**C → 他们的目标函数里没有 ppl 锚。** 评测套件 20 项全是生成式基准、无困惑度——从未测量也就从未优化。这解释了镜像 trade-off 的站位选择：我们用 wiki 流+ppl 选点死保分布（1.014×），他们为基准全力让路（1.335× 是副作用不是选择）。M11 的内部证据支持此解读：sciq 剂量爬过 ppl 最优点后知识还在涨（ppl 最优@1000、sciq 最优@3000）——他们不过是走得比我们远得多。

**D → 自蒸馏或同家族教师。** 风格逐字保留排除异族教师；与 A 的推断一致。

**E → 与我方同族的 STE 式端到端 QAT。** 最大熵初始化签名 + 训练后保持（我方 zerofrac 全程 ~0.32 同现象）。

## 3. 反推出的官方方案要点（置信度标注）

1. **起点**：Qwen3.8-27B → Hadamard 折叠 + 最大熵三值初始化 → Z+STE 式端到端 QAT（高置信，E+契约）
2. **大规模混合蒸馏**：通用数据（自教师 KL）+ **海量任务对症语料矩阵**（知识/IF/数学/代码，与其 20 基准逐类对齐；高置信，A+B）+ 工业算力填充容量
3. **无 ppl 锚**：目标=基准分，分布维不设防（高置信，C+套件构成）
4. **可能多阶段链式**（base QAT → 任务定向，如我方链但更深；中置信）
5. **教师=27B 自身**（中高置信，A+D 的合流推断；余量分析可终判）
